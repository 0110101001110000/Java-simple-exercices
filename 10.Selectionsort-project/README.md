

# Insertion Sort Project


O projeto implementa o algoritmo Insertion Sort para classificar os registros presente em um arquivo de texto com base no tempo de volta de cada piloto, mantendo também os nomes dos pilotos ordenados, ou seja, primeiro ordena o tempo e logo após os nomes dos pilotos caso haja repetição de tempo. Após a ordenação, o produto grava os registros ordenados em um novo arquivo de texto.

O arquivo de texto fornecido contém informações sobre 20.000 registros de voltas rápidas. Cada registro possui quatro campos: data, nome do piloto, nome da equipe e o tempo de volta de cada piloto.

**Tecnologias:**

*   **Linguagem:** Java
*   **Algoritmo:** Insertion Sort
