O projeto consiste em uma plataforma digital desenvolvida para facilitar a 
reserva de poltronas em salas de cinema, ela implementa uma API REST com o armazenamento realizado em arquivos de texto, assim como uma interface gráfica com tela para cadastro, login e uma principal para reserva das poltronas.

Após o login, os usuários serão apresentados a uma tela de reserva que contém 100 botões, cada um representando um assento. Ao clicar em um botão, o sistema indicará se o assento está ocupado ou desocupado, proporcionando uma experiência interativa e intuitiva.

**Tecnologias:**

*    **Linguagem:** Java
*    **Framework:** Spring
*    **Bibliotecas:** Swing, Gson, Java HTTP Client
