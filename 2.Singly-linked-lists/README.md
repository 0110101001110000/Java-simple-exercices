

# Singly Linked List


Este projeto consiste em uma implementação básica de uma estrutura de dados baseada em uma "Lista Simplesmente Encadeada" utilizando a linguagem de programação Java. O objetivo principal foi aplicar conceitos de estruturas de dados e programação orientada a objetos em um cenário prático.

O desenvolvimento foi realizado como parte de um exercício avaliativo para uma disciplina da universidade. O prazo total para a concepção, desenvolvimento e testes foi de uma semana, porém, esse fato não impede a atualização do presente repositório mesmo após a entrega do projeto.
