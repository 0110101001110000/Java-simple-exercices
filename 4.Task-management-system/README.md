# Task Management System

Este projeto é um Sistema de Gerenciamento de Tarefas (Task Management System) simples, composto por um backend desenvolvido em Java e um frontend gráfico (GUI) desenvolvido em Python utilizando a biblioteca Tkinter (ttkbootstrap). A comunicação entre o frontend e o backend é realizada através de uma API REST. O backend utiliza uma estrutura de dados própria de Lista Duplamente Encadeada para armazenar e gerenciar as tarefas.

O desenvolvimento foi realizado em grupo como parte de um exercício avaliativo para uma disciplina da universidade. Os membros da equipe foram [@0110101001110000](https://github.com/0110101001110000), [@fragamateus](https://github.com/fragamateus) e [@carloskayky](https://github.com/carloskayky). O prazo total para a concepção, desenvolvimento, testes, documentação e apresentação foi de uma semana, porém, esse fato não impede a atualização do presente repositório mesmo após a entrega do projeto.

Além da implementação do código-fonte em Java, o escopo do trabalho envolveu a criação de artefatos de engenharia de software (Somente para a Lista Duplamente Encadeada (db) que era o foco), como a documentação de especificação dos requisitos do sistema, a especificação detalhada da modelagem UML (Unified Modeling Language), o diagrama UML correspondente e a documentação do código utilizado para explicar os principais métodos.
