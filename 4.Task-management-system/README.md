# Task Management System Repository

O Sistema de Gerenciamento de Tarefas serve para armazenar e organizar atividades de forma eficiente. Ele permite adicionar, remover e listar tarefas, facilitando o controle das pendências do usuário. Com essa abordagem, a estrutura garante flexibilidade e otimização na manipulação dos dados. A estrutura da lista permite manipulações rápidas sem a necessidade de realocação de memória, garantindo melhor desempenho.
